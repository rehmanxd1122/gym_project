# FitZone Gym — Web Technologies Project 1

**Theme:** FitZone Gym | **Route:** B — design from scratch | **Pages:** Home, Media & Info, Register, Services, Portfolio, Contact.

## Run the website
1. Extract this ZIP.
2. Open the `FitZone-Gym` folder in VS Code.
3. Install the Live Server extension if needed.
4. Right-click `index.html` → **Open with Live Server**.
5. Use the navigation links to test all six pages. External sample media requires internet.

## Assignment concepts
- **Home:** semantic headings/paragraphs, image, navigation links, element/class/ID selectors, typography, borders and backgrounds.
- **Media & Info:** image, video, audio, lists, table, box model, background, display, position, float and overflow.
- **Register:** text/password/email/date/url/color/number/time/range/textarea/select/file/radio/checkbox; required, readonly, disabled, min/max, minlength/maxlength, checked/selected; attribute selectors, combinators and form pseudo-classes.
- **Services:** image cards with heading/text/link; Flexbox, wrap, justify, align, gap, transform and transition.
- **Portfolio:** gallery captions, Grid areas, keyframes and two media-query breakpoints.
- **Contact:** about/contact details, form, responsive Grid/Flexbox, media query, DOM form check and theme toggle.

## Viva practice
1. Grid is useful for rows and columns; Flexbox is useful for arranging items in a row/column and wrapping them.
2. `box-sizing: border-box` includes padding and border within the declared width/height.
3. `:focus` styles a selected input; `:valid` and `:invalid` respond to validation state.
4. `addEventListener` runs a function for an event; `preventDefault` stops the default form action.
5. `classList.toggle` adds a class if absent and removes it if present.
